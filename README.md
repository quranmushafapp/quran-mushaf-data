# quran-mushaf-data

Mushaf page packs and other downloads for the **Quran Mushaf** app. The app fetches these files
from this repository's [Releases](../../releases); there is no code here.

## Madani mushaf pack

| Release | File | Size | SHA-256 |
|---|---|---|---|
| `madani-v1` | `madani-pack-1.zip` | 134,882,864 bytes | `75a946b4687c67b2…` (full value in the release notes) |

604 page images (WebP) of **Mushaf al-Madinah** (Hafs 'an 'Asim), made from the free digital copy
published by the **King Fahd Glorious Qur'an Printing Complex** (1441 AH), as mirrored on
archive.org: <https://archive.org/details/MushafMadinaHafsGreen1441>.

The Complex permits free use of its digital Mushaf al-Madinah in software, websites and individual
businesses, inside and outside Saudi Arabia. Its usage rights, as archived, are kept in
[`licences/kfgqpc-madani-mushaf.txt`](licences/kfgqpc-madani-mushaf.txt).

The pages are the Complex's work and are reproduced unaltered except for cropping and resizing for
phone screens. Please report any error in a page through this repository's Issues.

All praise is for Allah.
